## O que você encontra

A palestra relaciona a evolução das interfaces de IA às CLIs de programação, às skills, ao Model Context Protocol (MCP) e aos agentes com memória persistente. Os exemplos mostram como conectar pedidos em linguagem natural a ferramentas, artefatos e verificações de uma operação.

O Hermes Agent é um projeto open source da **Nous Research e de sua comunidade**. Felipe ensina e utiliza a ferramenta; não é seu criador.

## Executar localmente

O site é estático e não depende de contas de IA, APIs ou credenciais.

```bash
python3 -m http.server 8000 --directory site
```

Abra `http://localhost:8000`. Use as setas para navegar e os controles do rodapé para índice, tela cheia e downloads.
